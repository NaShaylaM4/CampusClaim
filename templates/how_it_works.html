How CampusClaim Works

CampusClaim helps students report lost and found property, review ownership claims, and coordinate returns with confidence.

01

If You Lost Something

  1. Create a LOST report.
  2. Browse FOUND reports.
  3. If you find a possible match, open the FOUND report.
  4. Submit an ownership claim.
  5. Answer the finder's private verification question.
  6. Wait for the finder to approve or reject the claim.
  7. If approved, coordinate the item's return with the finder.
02

If You Found Something

  1. Create a FOUND report.
  2. Provide general information about the item without revealing every identifying detail.
  3. Add a private verification question that the real owner should know.
  4. Wait for ownership claims.
  5. Review the claimant's verification answer and optional message.
  6. Approve the person you believe owns the item or reject claims that do not verify ownership.
  7. Coordinate the return with the approved claimant.
  8. Mark the item RETURNED after it has been given back.
Important: Users do not submit claims against LOST reports. Claims are submitted only against FOUND reports.

Item statuses

OPEN
The report is active.
CLAIM_PENDING
One or more ownership claims are being reviewed.
RETURNED
The found item has been returned to its owner.
CLOSED
The report is no longer active.

Claim statuses

PENDING
Waiting for the finder to review the claim.
APPROVED
The finder accepted the ownership claim and return coordination can begin.
REJECTED
The finder could not verify ownership from the information provided.
